# 안녕하세요, 곽다윗입니다 👋

배우 매니지먼트 현장에서 8년간 일하다 백엔드 개발자가 되기로 했습니다.

여러 외부 서비스를 나눠 쓰던 불편함을 해결하려고 Python으로 배우 데이터 관리 시스템을 직접 만들었고,
800명의 데이터를 관리하는 이 시스템은 지금도 회사에서 쓰이고 있습니다.
그 경험으로 "불편함을 시스템으로 바꾸는 일"이 제 일이라는 걸 알게 됐습니다.

지금은 Java와 Spring으로 백엔드의 기본기를 단단히 다지고 있습니다. 만드는 사람과 쓰는 사람 사이의 간극을 줄이는 개발자가 목표입니다.
